# Sistema de Agendamento de Serviços - A Casa Manybe

## Descrição:

Este projeto consiste em um sistema de agendamento de serviços para salão de beleza, com duas áreas distintas:

- **Área do Cliente:**
- Permite realizar seus agendamentos;
- Consultar horários disponíveis;
- Receber a confirmação de serviços;
- Realizar e cancelar agendamentos;
- Ter acesso a Aba "Sobre Nós". Onde foi prepado para que cada cliente entenda o propósito, amor e cuidado por trás da Manybe. Onde também possa  ver endereço, telefone e ter acesso as redes sociais para acompanhar os trabalhos e portifólio.
  

  **Área Administrativa:**
- Permite visualizar todos os agendamentos com filtros de datas e profissionais, pesquisa por clintes ou serviços;
- Permite vizualizar os dados dos clientes, cancelamento, exclusão ou edição de agendamentos e dados;
- Contém históricos de atendimentos anteriores com serviços realizados, produtos e quantidades utilizadas, valores cobrados e formas de pagamento;
- Possibilidade de bloqueio de agenda por profissionais com ajuste de datas, periodo e justificativa.
- Aba para adicionar novos procedimentos e valores.

# Decisões Técnicas Adotadas

- O projeto foi desenvolvido utilizando HTML, CSS e JavaScript para garantir simplicidade, desempenho e facilidade de manutenção.
- A interface foi organizada de forma intuitiva para proporcionar uma boa experiência ao usuário.
- O layout foi desenvolvido de forma responsiva, permitindo o uso em computadores, tablets e smartphones.
- O código foi estruturado em arquivos separados (HTML, CSS e JavaScript), facilitando a organização e futuras manutenções.
- As funcionalidades foram implementadas com foco na usabilidade, impedindo ações indevidas e tornando o fluxo de agendamento simples e eficiente.
- O desing foi inspiradado na identidade da marca e das proprietarias.
